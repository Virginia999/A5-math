# 智慧知识库系统设计文档

## 1. 系统概述

### 1.1 项目背景
智慧知识库是一个基于人工智能技术的企业级知识管理平台，旨在帮助组织高效管理、检索和利用知识资源。本项目参加大学生软件设计大赛，展示了多项前沿技术的创新应用。

### 1.2 核心价值
- **智能化**: 集成RAG、知识图谱等AI技术，实现智能问答和知识推理
- **协作化**: 支持多人实时协作编辑，促进知识共享
- **个性化**: 基于混合推荐算法，提供个性化知识推荐
- **可视化**: 知识图谱可视化展示，直观呈现知识关联

### 1.3 技术亮点
1. **RAG检索增强生成**: 结合向量检索和大语言模型，实现精准的知识问答
2. **知识图谱构建**: 自动从文档中提取实体和关系，构建知识图谱
3. **混合推荐系统**: 融合内容推荐、协同过滤和知识图谱推荐
4. **实时协作编辑**: 支持多人同时编辑，实时同步
5. **贡献度评估**: 科学的激励机制，促进知识贡献

## 3. 核心模块设计

### 3.1 RAG检索增强生成模块

#### 3.1.1 架构设计
```
用户查询 → 查询向量化 → 向量检索 → 混合搜索 → 重排序 → 上下文构建 → LLM生成 → 结果返回
```

#### 3.1.2 核心流程
1. **文档预处理**: 分块 → 向量化 → 存储
2. **检索阶段**: 向量检索 + 关键词检索 → 混合排序
3. **生成阶段**: 上下文构建 → LLM推理 → 引用溯源

#### 3.1.3 技术参数
| 参数 | 默认值 | 说明 |
|------|--------|------|
| topK | 5 | 检索文档数量 |
| similarity_threshold | 0.7 | 相似度阈值 |
| max_context_length | 4000 | 最大上下文长度 |
| chunk_size | 500 | 文档分块大小 |

### 3.2 知识图谱模块

#### 3.2.1 数据模型
```
知识节点 (KnowledgeNode)
├── id: 唯一标识
├── concept: 概念名称
├── nodeType: 节点类型 (CONCEPT/ENTITY/EVENT/ATTRIBUTE)
├── description: 描述
└── confidence: 置信度

知识关系 (KnowledgeRelation)
├── sourceNode: 源节点
├── targetNode: 目标节点
├── relationType: 关系类型
├── weight: 权重
└── evidence: 证据文本
```

#### 3.2.2 核心功能
- **实体提取**: 使用LLM从文档中提取实体
- **关系抽取**: 识别实体间的关系
- **知识推理**: 基于图谱路径进行推理
- **可视化**: 生成图谱可视化数据

### 3.3 推荐系统模块

#### 3.3.1 混合推荐算法
```
最终得分 = 0.4 × 内容推荐分 + 0.3 × 协同过滤分 + 0.3 × 知识图谱分
```

#### 3.3.2 推荐策略
| 策略 | 权重 | 说明 |
|------|------|------|
| 内容推荐 | 40% | 基于向量相似度 |
| 协同过滤 | 30% | 基于用户行为相似性 |
| 知识图谱 | 30% | 基于知识关联 |

### 3.4 协作编辑模块

#### 3.4.1 架构设计
```
客户端A ──┐
          ├──→ WebSocket服务器 ──→ 操作转换(OT) ──→ 广播同步
客户端B ──┘
```

#### 3.4.2 核心功能
- 权限管理 (所有者/编辑者/查看者/评论者)
- 实时光标同步
- 操作历史记录
- 冲突解决

### 3.5 贡献度评估模块

#### 3.5.1 评分公式
```
总分 = 10×创建文档数 + 5×编辑次数 + 2×评论数 + 8×回答数 + 3×获赞数
```

#### 3.5.2 激励机制
- 月度排行榜
- 成就徽章
- 等级体系
